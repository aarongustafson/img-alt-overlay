<img-alt-overlay> via unpkg

Automatic registration from the latest published package. See the README.

Load the registration entry point

This URL requires a published package. Failed loading leaves the image usable without adding a dead control. Prefer a pinned version for production. 

<script type="module"
  src="https://unpkg.com/@aarongustafson/img-alt-overlay@latest/define.js?module">
</script>
