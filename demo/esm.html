<img-alt-overlay> via esm.sh

A class-only import with manual registration. See the README.

Import and register the class

This pinned URL works after this version is published. If loading fails, the image stays visible and no nonfunctional controls appear. 

import { ImgAltOverlayElement } from
  'https://esm.sh/@aarongustafson/img-alt-overlay@1.0.0/img-alt-overlay.js?bundle&target=es2022';

customElements.define(
  'img-alt-overlay', ImgAltOverlayElement
);
